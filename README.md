# Sınıf Ortalama Hesaplama Uygulaması

Bu proje, Python programlama dili kullanılarak geliştirilmiş basit bir konsol uygulamasıdır. 
Kullanıcıdan alınan öğrenci notlarına göre sınıf ortalaması hesaplanmaktadır.

##  Projenin Amacı

Bu proje aşağıdaki temel Python konularını pekiştirmek amacıyla geliştirilmiştir:

- Değişken kullanımı
- Döngüler
- Koşul yapıları (if-else)
- Kullanıcıdan veri alma
- Ortalama hesaplama mantığı

##  Kullanılan Teknoloji

- Python 3

##  Nasıl Çalıştırılır?

1. Bilgisayarınızda Python 3 yüklü olmalıdır.
2. Proje dosyasının bulunduğu klasöre gidin.
3. Terminal veya komut satırında aşağıdaki komutu çalıştırın:

python sinifOrtalamasiUygulama.py
